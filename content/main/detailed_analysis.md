# 詳細データと予測の前提

2026年10月から、試験の完了率を成功率とする前提を撤回し、眼科平均とRP過去の2シナリオに変更しました。

| 段階 | BIO眼科の通過率 |
|---|---|
| 第1相→第2相 | 71.6% |
| 第2相→第3相 | 35.5% |
| 第3相→申請 | 51.2% |
| 申請→承認 | 91.1% |

出典: [BIO Clinical Development Success Rates 2011–2020](https://go.bio.org/rs/490-EHZ-999/images/ClinicalDevelopmentSuccessRates2011_2020.pdf)。RP過去シナリオは進行抑制の第3相だけ11.1%です。遺伝子治療の第3相×0.9と進行抑制の相関0.5はいずれも仮定です。

## AIは開発をどこまで速くできるか

**要点: AIは薬や遺伝子の運び屋を「設計する」前半を数倍速くしていますが、人で効果を確かめる後半（臨床試験・安全性の観察・審査）は体と時間が相手で、AIが賢くなっても同じ割合では縮みません。**

以前このページにあった「最大50%短縮」「2025年内に最初の承認」という見通しは、根拠が弱く実際にも外れたため、2026年10月に取り下げました。

| 部分 | AIの効き方 | 根拠 |
|---|---|---|
| 標的探し〜候補の決定 | 速くなっている。4〜6年かかる区間が18か月になった実例がある | [Nature Biotechnology 2024（Insilico Medicine の肺線維症薬）](https://www.nature.com/articles/s41587-024-02143-0) |
| 臨床試験での有効性 | 優位は確認されていない。AI由来の薬の第2相の成功率は約40%で業界平均と同程度（完了試験は約10件と少ない） | [Drug Discovery Today 2024](https://www.sciencedirect.com/science/article/pii/S135964462400134X) |
| 全体の期間 | 縮められない時間（細胞や動物の実験、病気の進行、安全性の観察）が残り、そこが全体を決める | [Hebenstreit ら、AIによる研究加速の限界の定式化](https://arxiv.org/pdf/2508.16613) |
| 規制 | FDAの2025年1月の指針案は、AIを試験短縮の手段としては位置づけず、用途のリスクに応じた信頼性の検証を求めている | [Federal Register 2025-01-07](https://www.federalregister.gov/documents/2025/01/07/2024-31542) |

網膜色素変性は進行がゆっくりなので、「遅らせた」と証明するには年単位の観察が要ります（NACの最終試験は45か月）。この部分は知能では縮みません。

一方で、縮められる余地が残っている部分もあります。

- **評価の方法**: 網膜の断層撮影で測る視細胞の層の幅など、変化を早く捉えられる指標を使う
- **試験の設計**: 少ない人数・短い期間で効果を示せる設計にする
- **設計の前半**: 大きすぎて運べない遺伝子（EYS、USH2A など）の運び方の設計

このサイトの予測は過去の成功率と所要年数を使っているため、AIで候補の数が増えたり設計が速くなったりすれば、実際は予測より良くなる可能性があります。その意味で予測は保守的です。

## 開発のボトルネック

網膜色素変性症治療開発における主要な課題と、その解決に向けた取り組みを分析します。

<div class="bottleneck-item">
<h3>1. 患者募集の困難さ</h3>
<p><strong>問題：</strong>希少疾患のため、臨床試験に必要な患者数の確保が困難（試験あたり50-200名必要）</p>
<h4>影響</h4>
<ul>
<li>募集期間の長期化（平均2-3年）</li>
<li>地理的制約（専門施設への通院）</li>
<li>遺伝子型特異的試験での更なる絞り込み</li>
</ul>
<div class="solution-box">
<h4>解決策</h4>
<ul>
<li><strong>患者レジストリ構築</strong>：日本網膜色素変性症協会（約4,000名）との連携</li>
<li><strong>国際共同治験</strong>：複数国での同時実施</li>
<li><strong>リモート臨床試験</strong>：在宅での評価項目導入</li>
<li><strong>AI活用</strong>：電子カルテからの適格患者抽出</li>
</ul>
</div>
</div>
<div class="bottleneck-item">
<h3>2. ベクター製造と免疫原性</h3>
<p><strong>問題：</strong>AAVベクターの大量製造が困難で、既存抗体保有者は治療対象外</p>
<h4>影響</h4>
<ul>
<li>製造コスト：1患者分100-300万ドル</li>
<li>AAV既存抗体保有率：30-60%</li>
<li>スケールアップに2-3年必要</li>
</ul>
<div class="solution-box">
<h4>解決策</h4>
<ul>
<li><strong>新規ベクター開発</strong>：免疫原性の低いAAV改変体</li>
<li><strong>製造技術革新</strong>：合成生物学による効率化</li>
<li><strong>免疫抑制プロトコル</strong>：一時的免疫抑制の併用</li>
<li><strong>代替デリバリー</strong>：非ウイルスベクター（LNP等）</li>
</ul>
</div>
</div>
<div class="bottleneck-item">
<h3>3. 有効性評価の標準化</h3>
<p><strong>問題：</strong>視機能改善の客観的評価が困難、プラセボ効果の除外が必要</p>
<h4>影響</h4>
<ul>
<li>主要評価項目の設定困難</li>
<li>規制当局間での基準不統一</li>
<li>長期フォローアップの必要性（5年以上）</li>
</ul>
<div class="solution-box">
<h4>解決策</h4>
<ul>
<li><strong>新規評価法開発</strong>：AI画像解析による網膜構造評価</li>
<li><strong>複合エンドポイント</strong>：視力＋視野＋QOL</li>
<li><strong>バイオマーカー探索</strong>：血液・涙液マーカー</li>
<li><strong>国際標準化</strong>：FDA-EMA-PMDA協調</li>
</ul>
</div>
</div>
<div class="bottleneck-item">
<h3>4. 規制要件とコスト</h3>
<p><strong>問題：</strong>希少疾患薬開発の高コスト（10-20億ドル）と長期間（10-15年）</p>
<h4>影響</h4>
<ul>
<li>ベンチャー企業の資金調達困難</li>
<li>大手製薬会社の参入躊躇</li>
<li>患者アクセスの制限</li>
</ul>
<div class="solution-box">
<h4>解決策</h4>
<ul>
<li><strong>規制優遇措置</strong>：オーファンドラッグ指定、優先審査</li>
<li><strong>官民パートナーシップ</strong>：AMED等の公的支援</li>
<li><strong>革新的価格モデル</strong>：成果報酬型、分割払い</li>
<li><strong>プラットフォーム技術</strong>：複数疾患への応用</li>
</ul>
</div>
</div>
<h3>統合的アプローチの必要性</h3>
<p>これらの課題は相互に関連しており、単独での解決は困難です。産学官患の連携による統合的アプローチが必要です：</p>
<ol>
<li><strong>エコシステム構築</strong>：研究機関・企業・患者団体の連携強化</li>
<li><strong>データ共有基盤</strong>：競合前領域でのオープンイノベーション</li>
<li><strong>人材育成</strong>：遺伝子治療専門家の養成</li>
<li><strong>社会的理解</strong>：遺伝子治療への理解促進</li>
</ol>
