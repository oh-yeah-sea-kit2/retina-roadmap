## 注意事項

1. **段階的リリース可能**
   - まずindex.htmlとpatient_guide.htmlだけでも公開可能
   - 他のページは順次追加

2. **ロールバック計画**
   - 旧ファイルは削除せずバックアップ
   - 問題があれば即座に戻せる体制

3. **ユーザーテスト**
   - 可能であれば実際の患者・医療従事者に確認してもらう
